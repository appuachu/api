API Documentation v2.0

Welcome to our API documentation. All endpoints require authentication in v2.

API Version 2 Endpoints

GET /api/v2/users

Description: Retrieve list of users

Authentication: Required

Response: JSON array of users

curl -X GET https://example.com/api/v2/users

GET /api/v2/user/{id}

Description: Retrieve specific user by ID

Parameters: user_id (integer)

Response: JSON user object

curl -X GET https://example.com/api/v2/user/1001

POST /api/v2/user/{____}

Description: Get special access flag

Request Body: JSON with user credentials

Example:


  "user": "username","role": "user_role"

Response: JSON with access result
